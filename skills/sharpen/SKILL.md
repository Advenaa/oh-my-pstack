# Sharpen

Make this task deeper, not bigger. Say these four things first, then rewrite the prompt to ask for exactly what they point at.

1. What a top professional in this field would do here that the user is not asking for.
2. The rawest material they would start from, instead of what has already been digested for the user.
3. The specific methods and tools they would use.
4. What, other than the agent or the user, would show the result is right.

Leave choices that are the user's to make open instead of deciding them.
